# Cross-Document Checks — Officer Guide

These checks compare information across application documents. A finding flags a discrepancy for review; it does not by itself establish wrongdoing.

## 1. X-NAME — Institution name mismatch

Checks whether the institution name in a document differs from the name declared in the application or record. Review the names and confirm whether the difference is meaningful.

## 2. X-FUTURE-DATE — Future date

Checks date fields for dates later than the current processing date. Verify the date against the source document and application timeline.

## 3. X-PERMID — Permanent ID mismatch

Compares the Permanent ID on the previous year's EoA letter with the application's Permanent ID. Check whether both refer to the same institution.

## 4. X-FIRE-DATES — Fire certificate date inconsistency

Checks whether the fire certificate's validity end date is consistent with its issue date. A validity end date on or before the issue date needs review.

## 5. X-APPID — Application ID repeated across years

Compares the Application ID on Affidavit 2 with the Application ID on the previous year's EoA letter. If they are equal, verify that the affidavit relates to the current year's application.

## 6. X-SWORN-AFTER-SUBMIT — Affidavit sworn after submission

Checks whether the affidavit's sworn date is later than the application submission date. Review both dates and confirm the timeline.

## 7. X-PROG-NOT-APPROVED — Programme not found in previous EoA approval

Checks programmes listed in the university NOC against programmes listed in the previous EoA approval. A programme not found in the previous approval needs verification.

## 8. X-INTAKE — Intake discrepancy

Compares intake information in the university NOC with the previous EoA approval, using the applicable category rules. Verify any discrepancy against the source documents.

## 9. X-ERROR — Cross-check could not complete

Indicates that a cross-document check encountered an error and could not complete normally. A human should review the application and investigate the issue.

## Officer guidance

- Check the relevant source documents before acting on a finding.

- Treat discrepancies as prompts for verification, not as final decisions.

- If information is missing, unclear, or inconsistent, refer it for human review.

- Record the evidence and reasoning behind any follow-up action.
