# Terms of use - Pramaan (plain language)

1. **What it is.** Pramaan is decision support for AICTE scrutiny officers checking Extension of Approval applications. Its
   findings are advisory. The competent officer decides and signs; letters it drafts say so.
2. **No automatic outcomes.** The tool sorts applications into "return for rectification", "human review" or "clear". It never
   refuses an application by itself and never states that a document is false: it says "possible alteration, needs human review".
3. **Mock sources.** In this version checks against outside sources are simulated (MOCK) and labelled as such everywhere.
4. **Numbers.** Scores (trust score, priority) are designed scores, not probabilities. Accuracy figures come from synthetic test
   documents unless a figure says "real" - see eval/results.csv.
5. **Translations.** Pages in Indian languages are machine-translated offline (IndicTrans2). The English version is authoritative.
6. **Use by institutes.** The self-check shows an institute what to fix before it submits. It is not a decision and is not seen
   as one by the officer.
7. **Records.** Actions are recorded in a tamper-evident audit log so that decisions can be explained (RTI, appeals).
